# 自定义背景与毛玻璃 (Background & Glass)

为 OpenListNext 页面提供**自定义背景**（纯色 / 图片 / 渐变，支持透明度与模糊），并可对页面**原有卡片与顶部导航栏**一键套用**毛玻璃效果**（透明度 + 模糊）。

## 功能亮点

- 🎨 **自定义背景**：支持纯色、图片直链、CSS 渐变三种模式，并可调节透明度与高斯模糊。
- 🪟 **界面毛玻璃**：顶部导航栏（`.header` / `.nav`）默认**全透明、无模糊**直接悬浮于背景之上；页面原有卡片自动套用半透明 + 高斯模糊，透明度与模糊半径均可单独调节。
- 💡 **点击状态不失效**：MutationObserver（DOM 结构与 class/style）+ 点击/聚焦事件即时补标 + 1.5 秒周期自愈三重保障，任意交互与渲染时序下毛玻璃都不会丢失。
- 🎨 **观感优化**：毛玻璃带 1.35 倍饱和度增强与 0.25s 平滑过渡，通透不发灰；透明导航栏文字图标自带投影，背景复杂时依然清晰可读。
- ⚙️ **后台可视化配置**：所有参数均可通过管理后台「配置」表单在线调整，无需改代码。
- 🌗 **深浅色自适应**：毛玻璃底色自动适配深色 / 浅色模式，避免白色发灰、深色发白。
- 🖌️ **滚动条美化**：细窄半透明滚动条，与毛玻璃风格统一。
- 🖌️ **排除干扰元素**：按钮、链接、图标、图片、视频、弹层（Modal / Drawer / Tooltip）不参与毛玻璃，后台管理页与登录页保持原生样式。
- ⚡ **轻量自愈**：只有在 DOM 结构 / class / style 变化或用户交互后才重扫标记，空闲时暂停扫描，避免全量计算样式导致页面卡顿。

## 配置项

| 配置项 | 说明 |
| ------ | ---- |
| 启用自定义背景 | 是否覆盖系统默认页面背景 |
| 背景类型 | 纯色 (color) / 图片 (image) / 渐变 (gradient) |
| 背景颜色 | 纯色模式下生效的背景色 |
| 背景图片链接 | 图片模式下生效的 HTTPS 直链地址 |
| 渐变样式 | 渐变模式下生效的 CSS background 渐变值 |
| 背景透明度 (0-100) | 背景层整体透明度，数值越小越透明 |
| 背景模糊 (px) | 大于 0 时对背景应用高斯模糊 |
| 启用界面毛玻璃 | 是否套用导航栏与卡片的毛玻璃效果 |
| 导航栏透明度 (0-100) | 顶部导航栏背景不透明度，越小越透（默认 0 全透明） |
| 导航栏模糊 (px) | 顶部导航栏背景高斯模糊半径（默认 0 无模糊） |
| 卡片透明度 (0-100) | 页面原有卡片背景不透明度，越小越透 |
| 卡片模糊 (px) | 页面原有卡片背景高斯模糊半径 |
| 卡片圆角 (px) | 毛玻璃卡片的统一圆角半径，0 表示保留系统原有圆角 |
| 额外指定毛玻璃元素 | 自动识别遗漏时兜底，填写 CSS 选择器（逗号分隔），如 `.left-toolbar, .hope-drawer__content` |

## 安装

1. 登录 OpenListNext 管理后台，进入 **管理面板 -> 插件管理 (Plugins)**。
2. 点击 **安装插件**，将 `oplist-plugin-bg-glass.zip` 拖入上传区。
3. 安装完成后点击 **启用**。
4. 点击 **配置**，在线调整背景与毛玻璃参数并保存。

## 实现说明

- 权限声明：仅申请最小权限 `dom:inject`（页面 DOM 注入）。
- 卡片识别：OpenList 前端基于 SolidJS + Hope UI，卡片类名为构建期随机 hash，无法静态选择。插件通过 `MutationObserver` 监听 DOM 结构与 class/style 属性变化，动态标记「有实色背景或卡片形态渐变背景」的元素为 `data-oplist-glass="true"` 并套用毛玻璃；点击选中、悬停等状态切换后会自动补标，不会丢失效果；首屏渲染后延迟两轮再补标一次；渐变背景卡片会额外清除图片层，保证透明度生效。
- 兜底方案：自动识别仍遗漏的组件（如自绘面板），可在「额外指定毛玻璃元素」中直接填 CSS 选择器。
- 命名规范：所有 CSS 类名均带 `oplist-bg-glass-` 前缀，避免污染系统页面。
