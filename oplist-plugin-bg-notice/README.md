# 自定义背景与公告 (Background & Notice)

为 OpenListNext 页面提供**自定义背景**（纯色 / 图片 / 渐变，支持透明度与模糊）与**站点公告挂件**。

## 功能亮点

- 🎨 **自定义背景**：支持纯色、图片直链、CSS 渐变三种模式，并可调节透明度与高斯模糊。
- 📢 **公告挂件**：悬浮展示站点公告，支持标题、多行内容、五种贴边位置与一键关闭。
- ⚙️ **后台可视化配置**：所有参数均可通过管理后台「配置」表单在线调整，无需改代码。
- 📱 **移动端友好**：公告卡片在小屏自动适配全宽，避免遮挡操作按钮。
- 🌗 **深浅色自适应**：公告卡片自动适配深色 / 浅色模式。

## 配置项

| 配置项 | 说明 |
| ------ | ---- |
| 启用自定义背景 | 是否覆盖系统默认页面背景 |
| 背景类型 | 纯色 (color) / 图片 (image) / 渐变 (gradient) |
| 背景颜色 | 纯色模式下生效的背景色 |
| 背景图片链接 | 图片模式下生效的 HTTPS 直链地址 |
| 渐变样式 | 渐变模式下生效的 CSS background 渐变值 |
| 背景透明度 (0-100) | 数值越小背景越透明 |
| 背景模糊 (px) | 大于 0 时对背景应用高斯模糊 |
| 启用公告挂件 | 是否在页面展示公告卡片 |
| 公告标题 / 公告内容 | 公告卡片展示的文本（内容支持多行） |
| 公告显示位置 | 右上角 / 左上角 / 顶部居中 / 右下角 / 左下角 |

## 安装

1. 登录 OpenListNext 管理后台，进入 **管理面板 -> 插件管理 (Plugins)**。
2. 点击 **安装插件**，将 `oplist-plugin-bg-notice.zip` 拖入上传区。
3. 安装完成后点击 **启用**。
4. 点击 **配置**，在线调整背景与公告参数并保存。

## 开发说明

- 权限声明：仅申请最小权限 `dom:inject`（页面 DOM 注入）。
- 结构：`plugin.json`（清单与配置架构）、`index.js`（主逻辑）、`style.css`（样式）、`icon.svg`（图标）。
- 命名规范：所有 CSS 类名均带 `oplist-bg-notice-` 前缀，避免污染系统页面。
